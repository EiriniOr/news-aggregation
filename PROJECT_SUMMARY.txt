================================================================================
QUICK START
================================================================================

1. Install dependencies:
   pip install anthropic requests feedparser openai

2. Set API keys:
   export ANTHROPIC_API_KEY="your-key"
   export OPENAI_API_KEY="your-key"

3. Run test:
   python3 generate_weekly_digest.py

4. Push to GitHub and configure Actions secrets

5. Enable GitHub Pages on gh-pages branch

================================================================================
AUTOMATION SCHEDULE
================================================================================

GitHub Actions runs every Monday at 6:00 AM UTC:
- Collects news from past 7 days
- Curates with Claude
- Generates webpage + audio
- Deploys to GitHub Pages

Can also be triggered manually via GitHub Actions UI
